# 📊 Projeto de Dashboard Interativo - Power BI

Este projeto foi desenvolvido como parte do aprendizado no **Bootcamp Primeiros Passos com Power BI**, oferecido pela [Digital Innovation One (DIO)](https://www.dio.me/).

O objetivo principal foi criar um relatório visualmente atraente, intuitivo e com navegação fluida para facilitar a análise de dados e a tomada de decisão.

---

## 🎯 Destaques e Funcionalidades

### 📈 Gráficos e Visualizações
O dashboard conta com diversos visuais construídos para fornecer métricas claras e insights rápidos:
* **Cards de KPIs:** Exibição clara das principais métricas do negócio.
* **Gráficos Temporais/Linhas:** Acompanhamento de tendências ao longo do tempo.
* **Gráficos de Categoria (Barras/Colunas):** Comparação detalhada de desempenho entre diferentes segmentos/categorias.
* **Filtros e Segmentadores de Dados:** Permitindo visões customizadas por período, região e outros atributos.

### 🔘 Interatividade e Navegação Avançada
Para garantir uma experiência de usuário (UX) excelente e intuitiva, foram implementados recursos nativos de navegação no relatório:
* **Botão Home:** Retorna o usuário instantaneamente à tela inicial/menu do relatório.
* **Botão Voltar:** Facilita a navegação para a página visualizada anteriormente.
* **Botão Avançar:** Permite prosseguir sequencialmente entre as páginas de análise.
* **Ações por Indicadores (Bookmarks):** Integração dos botões com indicadores para alterar visões de página com um único clique.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Power BI Desktop:** Modelagem de dados, criação de medidas DAX e construção dos visuais.
* **Power Query:** Tratamento, limpeza e transformação dos dados.
* **DAX (Data Analysis Expressions):** Criação de métricas personalizadas.

---

## 🎓 Contexto do Projeto

Projeto desenvolvido durante o **Bootcamp Primeiros Passos com Power BI - DIO**, com o intuito de praticar os conceitos fundamentais de:
1. Importação e tratamento de dados no Power Query.
2. Relacionamentos e modelagem em estrela (Star Schema).
3. Criação de medidas e colunas calculadas em DAX.
4. Design de dashboards e boas práticas de UX/UI com botões e navegação.

---

## 🚀 Como Visualizar o Projeto

1. Baixe o arquivo `.pbix` localizado neste repositório.
2. Abra o arquivo usando o **Power BI Desktop**.
3. Navegue pelas páginas utilizando os botões interativos do relatório!
